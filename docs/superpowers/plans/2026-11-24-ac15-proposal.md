# Đề xuất thay AC-15 và cập nhật tài liệu (CHƯA ÁP DỤNG — chờ Bảo duyệt)

Các file này được bảo vệ theo AGENTS.md §3. Chưa sửa file nào trong nhóm này cho đến khi Bảo ghi "duyệt".

## 1. `app/scripts/selftest.mjs` — khối AC-15 (khoảng dòng 296)

Hiện tại: kiểm tra không có route `/confirmation`, `/payment`, `/booking`. Route này không còn đúng sau khi bỏ AC-15
(đã có `/checkout/:ref/...` và `/receipt/:ref`).

Đề xuất: giữ mã `"AC-15"` để báo cáo vẫn là 15/15, đổi tiêu đề và nội dung. Thân khối mới:

```js
await test("AC-15", "Checkout: Price → Thanh toán → Biên lai", "Chuyến đã lưu → giá → số điện thoại → thanh toán → biên lai", async () => {
  const saved = await page.request.post(`${BASE}/api/customer/bookings`, {
    data: { serviceName: "Airport Transfer", pickupLocation: "Manchester Piccadilly Station, M1 2PB", destination: "Manchester Airport Terminal 2, M90 4FP", journeyDate: "2027-09-15", journeyTime: "14:30", passengerCount: 3, vehicleSize: "seven-seater" },
  });
  const ref = (await saved.json()).booking.bookingRef;
  await page.goto(`${BASE}/checkout/${ref}/price`);
  await page.waitForSelector('[data-testid="fare-total"]');
  expect((await page.textContent('[data-testid="fare-total"]')) === "£114.75", "Giá không phải £114.75");
  await page.check('[data-testid="agree-fare"]');
  await page.click('[data-testid="continue-to-payment"]');
  await page.click('[data-testid="notify-next"]');
  await page.fill("#notifyPhone", "+44 7700 900123");
  await page.click('[data-testid="notify-pay"]');
  await page.waitForURL(`**/checkout/${ref}/success`);
  expect((await page.textContent('[data-testid="payment-ref"]')).startsWith("TXN-"), "Thiếu mã giao dịch");
  await page.click('[data-testid="view-receipt"]');
  await page.waitForSelector('[data-testid="receipt-total"]');
  return `Thanh toán ${ref} → biên lai £114.75`;
});
```

Ghi chú: thân này gọi lại đúng các bước trong `app/scripts/test-checkout.mjs` (CK-02…CK-05). Nếu Bảo muốn,
có thể bỏ phần lặp này và chỉ giữ kiểm tra route.
